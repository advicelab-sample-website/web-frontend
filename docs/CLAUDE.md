## Architecture Overview

### Tech Stack
- **Framework**: Vite + React 18 with TypeScript
- **UI Components**: shadcn/ui (built on Radix UI primitives)
- **Styling**: Tailwind CSS with custom theme configuration
- **Forms**: React Hook Form + Zod validation
- **Routing**: React Router v6 (SPA with client-side routing)
- **Data Fetching**: TanStack React Query (React Query)
- **Analytics**: Google Analytics 4 integration (via `usePageViewTracking` hook)
- **Other**: Recharts (charting), Sonner (toast notifications), Embla (carousels)

### Directory Structure
- **`src/pages/`** — Page components (one component per route). Includes nested directories like `services/`, `careers/` for grouped routes.
- **`src/components/`** — Reusable UI components. Subdirectories:
  - `ui/` — shadcn/ui components (auto-generated by `shadcn-ui` CLI)
  - `layout/` — Layout wrappers (e.g., `ScrollToTop`)
- **`src/hooks/`** — Custom React hooks:
  - `useBloggerPosts.ts`, `useBloggerPost.ts` — Fetch blog data (likely from Google Blogger API via React Query)
  - `usePageViewTracking.ts` — GA4 page view tracking
  - `useScrollAnimation.tsx` — Scroll-based animations
  - `use-mobile.tsx` — Responsive design hook
- **`src/lib/`** — Utility functions and helpers:
  - `analytics.ts` — Analytics event tracking
  - `utils.ts` — Class name utilities (likely `clsx`/`cn` helpers)
- **`src/config/`** — Configuration files:
  - `seo.ts` — SEO metadata configuration
- **`public/`** — Static assets (images, fonts, etc.)
- **`dist/`** — Build output (generated by `npm run build`)

### Routing (React Router v6)
Routes are defined in [App.tsx:38-54](src/App.tsx#L38-L54). Key structure:
- `/` — Home (Index page)
- `/about-us` — About page
- `/services` + nested routes (`/paraplanning`, `/clientsupport`, `/mortgage`)
- `/resources/blogs` — Blog listing
- `/blog/:id` — Individual blog post (dynamic route)
- `/careers` + nested routes (`/philippines`, `/srilanka`, `/job/:jobId`, `/submit-resume`)
- `/contact-us` — Contact page
- `*` — Catch-all 404 NotFound page

**Global Providers**: All routes are wrapped with QueryClientProvider (React Query) and TooltipProvider (Radix UI). ScrollToTop component auto-scrolls on navigation.

### Build & Deployment
- **Build tool**: Vite (configured in [vite.config.ts](vite.config.ts))
- **Deployment**: Vercel with client-side routing rewrite rule ([vercel.json](vercel.json)) — all routes redirect to `/` for SPA behavior
- **Component tagger**: Uses `lovable-tagger` in development mode for internal UI tagging
- **Never commit or push changes automatically** — leave changes staged/unstaged in the working tree. The user commits and pushes manually themselves.

### Styling System
- **CSS-in-JS**: None; uses utility-first Tailwind CSS
- **Color system**: CSS variables with HSL values (customizable via `--primary`, `--secondary`, etc.)
- **Theme**: Supports dark mode via `next-themes` (class-based: `dark` class on document)
- **Custom theme colors**: Sidebar, card, and component-specific color tokens defined in [tailwind.config.ts](tailwind.config.ts)

### State & Data Fetching
- **Server state**: React Query (TanStack Query) for managing async data from APIs
- **Client state**: React hooks (`useState`, `useContext`) — no global state manager (Redux, Zustand, etc.)
- **Blog data source**: Appears to be Google Blogger API (inferred from `useBloggerPosts` hook names)

## Development Patterns & Notes

### Adding New Components
- Use `npx shadcn-ui@latest add <component>` to add shadcn/ui components (auto-generates in `src/components/ui/`)
- Aliases are configured in [components.json](components.json) — use `@/components`, `@/hooks`, `@/lib`, etc. instead of relative paths

### ESLint Configuration
- ESLint config is in [eslint.config.js](eslint.config.js) (flat config format)
- Rules: Disables `@typescript-eslint/no-unused-vars` (unused vars are allowed)
- React Hooks plugin enforces proper hook usage; React Refresh warns on improper exports

### Pages & Routing
- Each page in `src/pages/` should be a React component exported as default
- For nested routes (e.g., service pages), create subdirectories within `pages/` (e.g., `pages/services/`, `pages/careers/`)
- Remember to add new routes to the `<Routes>` element in [App.tsx](src/App.tsx)

### Blog Integration
- Blog posts are fetched via `useBloggerPosts.ts` hook (React Query)
- Individual posts accessed via dynamic route `/blog/:id` and `useBloggerPost.ts` hook
- Blog metadata likely includes title, content, and post ID

### Type Checking
- TypeScript strict mode is enabled in [tsconfig.app.json](tsconfig.app.json)
- Check `src/vite-env.d.ts` for Vite type definitions

## Common Gotchas

- **Page tracking**: `usePageViewTracking()` hook is commented out in [App.tsx:33](src/App.tsx#L33) — uncomment to enable GA4 tracking
- **Mobile detection**: Use the `use-mobile` hook for responsive logic instead of media queries in components
- **Toast notifications**: Two systems are configured — Shadcn Toaster (for UI form notifications) and Sonner (for general notifications); check which is used in context
- **Dark mode**: Remember to respect `next-themes` context when adding new styled components; don't hardcode light colors
